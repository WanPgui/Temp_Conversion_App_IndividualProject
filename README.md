# Temperature Conversion App

## Overview

The Temperature Conversion App is a simple mobile application built with Flutter that allows users to convert temperatures between Fahrenheit and Celsius. The app features a user-friendly interface and provides a history of conversions for easy reference.

## Features

- **Temperature Conversion**: Convert temperatures between Fahrenheit and Celsius using the appropriate formulas.
- **History Tracking**: Keep track of previous conversions in a history list.
- **Theme Toggle**: Switch between light and dark themes for better visibility.
- **Input Validation**: Ensure that the user inputs valid temperature values.
- **Reset Functionality**: Clear the input fields and history with a single button press.
- **Responsive Design**: The app is designed to work consistently in both portrait and landscape orientations.
